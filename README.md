# AWS VPC Hands-On Project

## Project Overview

This project demonstrates a secure AWS VPC architecture using Public and Private Subnets.

## Services Used

* AWS VPC
* EC2 Instances
* Internet Gateway
* Route Tables
* Security Groups
* SSH (Git Bash)

## Architecture

* Public EC2 acts as a Bastion Host
* Private EC2 is accessed securely through the Public EC2

## Features

* Public & Private Subnets
* SSH Connectivity
* Secure Networking
* Route Table Configuration

## SSH Flow

Laptop → Public EC2 → Private EC2

## Learning Outcome

Learned practical cloud networking and secure server access in AWS.
